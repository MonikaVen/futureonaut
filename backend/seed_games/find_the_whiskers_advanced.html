How convolution finds whiskers
Y[i,j] = ΣₘΣₙ I[i+m,j+n]K[m,n]
The filter multiplies nine nearby pixels by nine kernel weights and adds the results.
A[i,j] = ReLU(Y[i,j]) = max(0,Y[i,j])
Only positive evidence remains.
whisker(i,j) = 1 if A[i,j] ≥ τ
τ is the threshold. High activations mark locations that resemble the horizontal whisker feature.

What this teaches

A single convolution filter usually detects a simple local feature, not a complete object part. Here, the first layer finds thin horizontal lines. Some of those lines are whiskers, but others can be unrelated edges or markings.
Why multiple convolution layers matter
Layer 1: pixels → simple lines and edges
Layer 2: line patterns → whisker-like structures
Layer 3+: whiskers + ears + eyes + fur → cat features
Deeper CNNs repeatedly convolve earlier feature maps. Each layer combines simpler patterns into more meaningful ones. So a later layer can learn that several horizontal line activations, positioned symmetrically around a face, are stronger evidence for whiskers than one isolated line somewhere else.
Main idea
Convolution is not just about finding one edge. A CNN builds a hierarchy of features: local pixel patterns become lines, lines become shapes, and shapes become recognizable object parts.
