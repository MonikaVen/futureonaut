What the model is learning
Start with small random values. They do not yet encode meaning.
How an embedding value is learned
1. Embedding matrix
E ∈ ℝ^(V × D)
V is vocabulary size and D is embedding dimension. In this game, V = 11 and D = 2, so E is an 11 × 2 matrix.
2. Random initialization
Eᵢⱼ ~ Normal(0, σ²)
The first values are small random numbers. They do not yet represent meaning.
3. Token ID selects a row
e_salmon = E[token_id(salmon)]
If salmon has ID 1001, the embedding operation selects the row assigned to token 1001.
4. Forward pass and loss
L = prediction error
The current embedding participates in a prediction. The loss measures how wrong that prediction is.
5. Gradient
∂L / ∂Eᵢⱼ
Backpropagation calculates how much changing each embedding value would change the loss.
6. Gradient-descent update
Eᵢⱼ(new) = Eᵢⱼ(old) − η · ∂L/∂Eᵢⱼ
η is the learning rate. The embedding value moves in the direction that reduces the loss.
7. Numerical example
E_old = [0.12, -0.31]
∇E L = [-0.60, -0.42], η = 0.5
E_new = [0.12, -0.31] − 0.5[-0.60, -0.42]
E_new = [0.42, -0.10]
8. Repeat across many training examples
E ← E − η∇E L
After many updates, useful semantic structure can emerge. In this teaching example, salmon eventually reaches [7.8, 7.1].
9. Why nearby words can mean similar things
distance(a,b) = √((a₁-b₁)² + (a₂-b₂)²)
If training pushes salmon and food toward similar useful representations, their vectors become close in the map.

Concept transition → Attention

Embeddings give every token a useful vector. But a word's meaning also depends on the other words around it. The next idea is attention: letting each token look at other tokens and decide which ones matter most.
