Weighted context
High-attention words contribute more strongly to the new context representation.
Scaled dot-product attention
1. Create Query, Key, and Value vectors
Q = XWQ    K = XWK    V = XWV
Each token embedding is transformed into a query, key, and value vector.
2. Compare query with keys
scoreᵢ = Q · Kᵢ
A larger dot product means the key is more relevant to the query.
3. Scale the scores
scaled scoreᵢ = (Q · Kᵢ) / √dₖ
4. Turn scores into attention weights
αᵢ = softmax(scaled scoreᵢ)
Softmax makes every weight positive and makes all weights sum to 1.
5. Build the context vector
context = Σ αᵢVᵢ
The final context is a weighted combination of the value vectors.

Concept transition → Self-attention

In this game, one token looks at the rest of the sentence. In a Transformer, every token does this. Each token builds its own context-sensitive representation using self-attention.
