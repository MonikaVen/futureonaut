Query, Key, and Value projections

The same input is projected into three representations with different functions.

Q

Search intent for each token.

K

Matchable description of each token.

V

Content passed to the output.

Causal masking

A decoder may attend to the current and previous positions, but not future positions.

Vocabulary projection and next-token probabilities

The final hidden state is multiplied by a vocabulary matrix to produce one logit for every possible token.

p(token k) = softmax(logitₖ / temperature)

All numerical values are intentionally small and illustrative so that the effect of each operation remains visible.
