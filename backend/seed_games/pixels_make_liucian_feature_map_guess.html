Images as matrices
Image = matrix of pixel values
16 × 16 = 256 numbers
A grayscale image stores one brightness value per pixel. A color image usually stores three values per pixel: red, green, and blue.
Why this matters for AI
A neural network does not initially see “Liucian.” It receives numbers. Later layers learn patterns such as edges, ears, whiskers, and fur.

3. Detected feature map

After convolution, the CNN stores the filter responses in a new grid called a feature map. Bright cells mean the kernel found a strong vertical edge at that location.

How to read it
Each feature-map cell corresponds to one 3 × 3 convolution window. Larger positive responses appear darker here, showing where strong vertical edges were detected.

What is this teaching?

Computer vision starts by converting images into numbers. Each pixel is one small measurement. A model learns useful patterns by combining many neighboring pixel values.
