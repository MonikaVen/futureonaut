What Lucian's world model is doing
👀

1. Observation

Lucian observes the moving mouse position/velocity, obstacle coordinates, and each moving person's position/velocity.

oₜ = [x_cat, y_cat, θ, x_mouse, y_mouse, mouse_vx, mouse_vy,
chair_x, sofa_x, sofa_y, table_x, table_y,
p1_x, p1_y, p1_vx, p1_vy, p2_x, p2_y, p2_vx, p2_vy]
chair / sofa / table coordinates define static obstacle geometry used by the planner.
🧩

2. Latent State

The room is compressed into useful variables.

zₜ = f_enc(oₜ)
Latent features include mouse distance, nearest-obstacle distance, heading error, and motion information from the moving people.
⚙️

3. Dynamics

Lucian predicts how each move changes his future state.

ẑₜ₊₁ = fθ(zₜ, aₜ)
Future states are rejected or penalized when Lucian intersects the chair, sofa, or table; moving people add time-dependent collision risk.
💭

4. Imagination

Lucian rolls forward multiple candidate futures.

(zₜ, Oₜ) → (ẑₜ₊₁, Ôₜ₊₁) → … → (ẑₜ₊ᴴ, Ôₜ₊ᴴ)
O contains static furniture plus predicted moving people. Every candidate future is checked against these obstacles.
🧠

5. Planning

He searches multi-step action sequences that avoid collisions with the chair, sofa, table, and predicted people while minimizing distance to the moving mouse.

J(A) = progress_to_mouse − μ·turn_cost − κ·collision
A* = argmax_A J(A),   A=[aₜ,…,aₜ₊ᴴ₋₁]
Obstacles are avoidance constraints: extra clearance gives no reward. Execute the first action of the best collision-free sequence, then re-plan.
