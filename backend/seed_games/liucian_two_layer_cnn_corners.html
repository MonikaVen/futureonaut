If at least one Layer 2 activation exceeds the threshold, the model has evidence for a sharp cat ear.
Two convolution layers
C = ReLU(I * K₁)
Layer 1 convolves the image I with corner kernel K₁, producing corner map C.
A = ReLU(C * K₂)
Layer 2 convolves the corner map C with ear kernel K₂, producing ear activation map A.
ear = 1 if max(A) ≥ τ
The threshold τ turns the strongest high-level feature activation into a simple detection decision.
14×14 → 12×12 → 10×10
Each 3×3 valid convolution with stride 1 reduces width and height by 2.
Y[i,j] = ΣₘΣₙ X[i+m,j+n]K[m,n] + b
The same mathematical operation is used at both layers; what changes is the meaning of the input features.

What is this teaching?

A CNN builds a feature hierarchy. Layer 1 does not need to understand “cat ear”—it only detects simple corners. Layer 2 combines those corner activations into a more meaningful shape. Deeper CNN layers can combine ears, eyes, whiskers, and fur into a full cat representation.
