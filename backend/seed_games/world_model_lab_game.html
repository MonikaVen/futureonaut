What the world model is doing Concept pipeline
👁️

1. Observation

Position, heading, goal, obstacle.

Observation vector:
oₜ = [x, y, θ, x_goal, y_goal, x_obs, y_obs]
🧩

2. Encoder

Compresses raw observation into a useful latent state.

zₜ = fenc(oₜ)
Here, z is a compact feature vector: distance-to-goal, obstacle proximity, heading error.
⚙️

3. Dynamics Model

Predicts what state comes next after an action.

ẑₜ₊₁ = fθ(zₜ, aₜ)
The model estimates how position and heading evolve under a chosen action.
🔮

4. Imagination

Rolls the learned dynamics forward several steps.

zₜ → ẑₜ₊₁ → ẑₜ₊₂ → … → ẑₜ₊ᴴ
H is the prediction horizon. Longer horizons provide more foresight but accumulate model error.
🧠

5. Planner

Scores possible futures and prefers safer, more useful ones.

Example objective:
J = −d(goal) − λ·risk + β·progress
The planner chooses the action with the highest predicted J.

A useful way to think about model-based control is:

Choose a* = argmaxₐ E[ Σ γᵏ rₜ₊ₖ ]

The agent selects the action expected to produce the best cumulative future reward. In real systems, the expectation may be estimated using a stochastic latent dynamics model.
